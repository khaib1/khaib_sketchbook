Before Peer Review

This is my initial design for my Projects page. I placed the projects on the left side of the page so that when viewers click on them, the project will open in a window without redirecting them to another page. I made this decision because I wanted to try something unique and create a clear visual hierarchy. However, it didn't turn out the way I imagined. I was also in a rush, so I didn't have time to add hover effects in CSS. After reading the peer feedback, I realized that I needed to make some adjustments to this section. The layout felt unclear because the project links on the left were too crowded, while the preview window took up most of the page. This made it harder for viewers to understand where to look first and which project they had selected. Without hover effects, the links also didn't give much visual feedback when viewers interacted with them.

After Peer Review

This is my revised version of the Projects page, and I think it looks much cleaner and more organized now. I moved all the projects to the top of the page to create a mini navigation bar, making it easier for viewers to find and switch between projects. This also gives the page a clearer visual hierarchy because the project links are separated from the preview window instead of being crowded on the left side. I also added hover effects in CSS to make the project links feel more like actual buttons. When viewers hover over a project, the visual change makes it clearer that the links are interactive and can be clicked. I think these changes make the page easier to navigate, improve the overall appearance, and help viewers focus on the project they want to see without being distracted by a crowded layout.
