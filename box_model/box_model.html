This project is very interesting. It introduces how to create boxes, the difference between padding and margin, and how to apply them in CSS. I think boxes is one of the most important part of a website. We can see boxes everywhere, from the navigation to the content and to the footer. I feel like boxes help connect the website together. To my understanding, margin is the space outside the box and padding is the space inside the box. If we want to make space between each elements of a website, we use margin. If we want to change the space inside the box, we use padding. Changing the display in CSS is also important if we want to adjust the content. For example, we can change the display to block for like bullet points, each bullet point will act as a block element. Similar to that, if we change the text display to inline, the text will appear natural from left to right without automatically creating new lines. As a result, I change the text to inline for the blockTo and change the display to block for the a.
